How NLP Works in FamilyCare

1. User Input: User describes symptoms using natural language.

2. Text Preprocessing: The system cleans and normalizes the entered text.

3. Symptom Extraction: Important health-related words are identified.

4. Possible Condition Identification: The extracted symptoms are matched with demo condition patterns.

5. Specialist Recommendation: A suitable medical specialty is suggested.

6. Hospital Search: The user can explore demo hospitals and doctors.
